# ✨ Premium Wedding Photography & Cinematography Portfolio Website ✨

### A Luxury Modern Wedding Studio Experience Built With Next.js 15

The Royal Pixel is a premium and modern wedding studio portfolio website designed to deliver a luxurious cinematic experience for wedding photography and cinematography businesses.

Built using modern frontend technologies like **Next.js 15**, **React 19**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, this project focuses on premium UI design, smooth animations, responsiveness, performance, and elegant user experience.

# 🚀 Getting Started

## 1️⃣ Clone Repository

```bash
git clone https://github.com/SiddharthKushwaha21/wedding-studio.git
```

---

## 2️⃣ Navigate To Project

```bash
cd wedding-studio
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Run Development Server

```bash
npm run dev
```

---

## 5️⃣ Open Browser

```bash
http://localhost:3000
```

---

# 📦 Build For Production

```bash
npm run build
```
